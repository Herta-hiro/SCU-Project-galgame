## 二、A3 是「打断事件」

A3（索引贴滑落，规则里是 8–16「任意一次同桌」）跨了 A1/A2 的区间，放进自动路由会互相抢，
所以做成**同桌中的打断**：从 `a1_third_day` 的「（点头，继续看书）」进入 `a3_tab`，
在那里面才是真正的分岔——

- 提醒但不伸手 → `a3_ok`，+2
- 直接去碰她的笔记本 → `a3_bad`，−5 并礼貌降温

想让它更容易出现，可以把 `a3_tab` 挂到任何同桌节点的选项上，加一行就行：

```
-> （她翻页时贴纸滑到桌沿）|a3_tab|||0
```

## 三、天府馆（另一个地点入口）

`hub_tiandu` 是独立的地点入口，从第二章开场（`ch2_open`）的「这周末去天府馆」进去：

| 好感 | 自动进入 | 事件 |
|---:|---|---|
| ≥71 | `e2_bench` | 公园长椅的十分钟 |
| 46–70 | `e1_afternoon` | 艺术馆的午后 |
| <46 | 停在 `hub_tiandu` | 还没到能偶遇的程度 |

E1 规则里是「≥46·周末」，E2 是「≥71·闭馆后」，这里用「E2 优先、E1 兜底」实现。

## 四、写法与调整

节点开头的路由块长这样：

```
:: hub
@bg bg_lib_window
@char shenzhiji:normal
@loc 省图三楼社科区靠窗
=> aff>=86 d4_confession
=> aff>=78 d3_cat
=> aff>=75 d2_exam
=> aff>=71 d1_tissue
=> aff>=60 c3_closing
=> aff>=50 c2_powerbank
=> aff>=46 c1_index
=> aff>=30 b3_topic
=> aff>=25 b2_tiandu
=> aff>=21 b1_return
=> aff>=10 a2_umbrella
=> aff>=5  a1_third_day
|（0-4：还没有能触发的事件）
-> 安静坐下|hub|||+1
```

改区间直接改数字；加事件就加一行 `=>`，记得**高门槛写在上面**。
每个节点最多 16 条路由，条件写法 `aff>=46` / `aff<=20` / `aff==0`。

## 四点五、0–20 铺满了（F1–F15）

原来的 0–20 只有 5 个事件，中间大段空白，只能靠「安静坐下 +1」硬点（0→21 大约 15–18 次点击）。
现在补到 15 个一次性小事件，**0→21 约 11 次点击，一次保底都不用点**。

```sh
gal.exe --shot node --node hub --aff N     # 换 N 看会进哪个事件
```

## 五、注意

- 路由是**进节点时**判定的，所以 `hub` 自己不带剧情，只做转发；
- 好感变化后重新进 `hub`（事件结束都回到 `hub`），才会走到下一档事件；
- 事件节点里的选项照样用第五列加减好感（`+2` / `-5`），和事件库里的结算保持一致；
- 校验器会检查：路由条数、条件写法、目标节点是否存在、指回自己。`python tools/check_script.py`

## 五点四、点击节奏（每档 6 次以内）

按「每个阶段 ≤6 次点击」重新配平：所有正向好感 ×3，保底「安静坐下」+9。

| 阶段 | 最差路径（每次都选扣分项） | 最好路径 |
|---|---:|---:|
| 0 → 21（B1） | 6 次 | 4 次 |
| 21 → 46（C1） | 6 次（累计 12） | 4 次（累计 8） |
| 46 → 71（D1） | 5 次（累计 17） | 4 次（累计 12） |
| 71 → 86（D4） | 4 次（累计 21） | 2 次（累计 14） |

改前同一路径是 37 / 63 / 98 / 116 次。

## 五点五、连败也不刷屏（扣分不倒退）

以前选到「碰笔记 −5」「追问 −3」这类负分选项，好感会被打回上一档，而上一档的事件已经演过，
只能靠保底硬点回去。现在加了一条规则：

> **负数只扣到「进这一场时的好感度」，不会把你打回事件之前。**

也就是越界当场会变冷、这一场没有进展，但不会退档，下一场照常按当前区间走。
实测最差路径（每次都选扣分选项）从 37 次点击降到 17 次（0→21），86 点从 116 次降到 50 次。

## 六、每个事件只演一次（@once）

事件节点标了 `@once A2`，进过一次就记进 `seen_mask`，之后 hub 的路由会跳过它。
本档事件演过之后**不会退回低档**，而是停在 hub，给出两个保底选项：

```
|（好感 0-4：还没有能触发的事件。先安静坐几天吧。）
-> 安静坐下|hub|||+1
-> 去天府馆看看|hub_tiandu|||0
```

「安静坐下」加 1 点好感，用来把好感推到下一档。`seen_mask` 会随存档保存（存档版本 v4），
读档后不会重演已经看过的事件。

调试时想验证“演过之后会跳过”，用 `--seen` 预置：

```sh
gal.exe --shot node --node hub --aff 30 --seen B3
# 输出 node=hub（B3 已演过，停在这里）
```
