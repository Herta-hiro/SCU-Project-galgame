> 现状：0–20 只有 4 个填充事件（F1–F4）+ A1/A2，中间大段空白，只能靠「安静坐下 +1」

> 目标：把 0–20 铺成 10 个左右的小事件，每个 +2 上下，**基本不用点保底**就能走到 B1。

## 二、新增事件正文（F5–F15）

### F5 桌上那滩水（好感 4）
```
|你的伞在滴水，桌脚积了一小滩。她看了一眼，把自己的纸巾盒推过来一半。
沈知霁|擦一下。
-> 抽一张，把水擦干|hub|||+2
-> 不用，我一会儿拖|hub|||+1
```

### F6 乱掉的索书号（好感 7）
```
|她对着电脑屏幕皱眉，手里的纸条上抄着一串索书号。
沈知霁|三楼这排……编号是乱的。
-> 我熟这排，帮你找|hub|||+2
-> 那去问前台吧|hub|||+1
```

### F7 三楼停电两分钟（好感 8）
```
|灯闪了两下，整层暗下来。有人小声抱怨。她合上书，没动。
沈知霁|……两分钟就好。
-> 开手机手电，照着她的桌面|hub|||+2
-> 一起等|hub|||+1
```

### F8 碰歪的书（好感 9）
```
|你起身的时候撞到桌角，她那摞地方志歪了一半，最上面一本滑到桌沿。
-> 立刻扶正，说对不起|hub|||+2
-> 看一眼，先走|hub|||-2
```

### F9 咳嗽与空杯子（好感 12）
```
|她压低声音咳了两下，端起杯子才发现是空的，又放下。
-> 把没喝过的水推过去|hub|||+2
-> 起身去接一杯，放她桌角|hub|||+3
-> 装作没听见|hub|||0
```

### F10 让座（好感 13）
```
|今天人多，你到的时候旁边已经坐满。她站在书架边，抱着包。
-> 起身把位置让给她|hub|||+2
-> 装作没看见|hub|||-1
```

### F11 关掉的台灯（好感 14）
```
|她起身去还书，路过时顺手把你这侧的台灯关了。
|你抬头，她已经走开两步。
-> 说声谢谢|hub|||+1
-> 自己重新打开，没说话|hub|||0
```

### F12 帮拿一半（好感 15）
```
|她抱着一摞书排在还书机前，队伍一动不动。
-> 帮她拿一半|hub|||+2
-> 在旁边等|hub|||+1
```
> 帮她拿时她会说「不用」，但没真的往回拽。

### F13 雨停后的门口（好感 16）
```
|雨停了。两人同时走到门口，玻璃门只开了一半。
|她往旁边让了半步，等你先过。
-> 你先过|hub|||+2
-> 一起出去|hub|||+1
```

### F14 她记得你的位置（好感 17）
```
|你进门的时候，她抬了一下头。
沈知霁|你今天没坐那边。
-> 那边没位置了|hub|||+2
-> （笑一下，坐下）|hub|||+1
```

### F15 闭馆前的电梯（好感 18）
```
|闭馆，电梯口排着队。她站在你前面两步，没说话。
|电梯到了，她没动，等后面的人先上。
-> 安静站着，等她先上|hub|||+2
-> 找话说：今天雨停了|hub|||+1
```

## 三、改动后的点击次数

| 路径 | 现在 | 改后 |
|---|---:|---:|
| 0 → 5（进 A1） | 4 次 | 5 次（全是有内容的事件） |
| 0 → 21（进 B1） | 约 15–18 次（含 8+ 次保底） | 约 11 次，**一次保底都不点** |
| 每档停留 | 常出现「只能安静坐下」 | 每一档都有具体的事 |

## 四、和现有内容的冲突检查

- F5–F15 都是 `@once`，演过不再出现；
- 区间不重叠，仍按「高门槛写在上面」排；
- A1/A2/B1 的区间不变，只是中间插了新事件；
- 全部事件合计 26 个，节点数约 75（上限 64 会超，需要把 `MAX_NODES` 提到 96）。

> 注意：节点上限要一起调，Windows 上 `Game` 结构体会变大（约 1.6 MB 静态区），
> 这个量没问题。
